HeLM helps it remember what already happened.

An explicit language memory connects a vision-language planner to a robot action policy—so each action follows progress through the whole task.

01 / THE PROBLEM

The same view.
A different thing to do.

After a button is released, the scene can look almost unchanged. A policy that sees only the current observation can repeat a completed action.

CURRENT OBSERVATION ONLY

“Which button is next?”

The image alone does not tell the robot which steps it already completed.

OBSERVATION + LANGUAGE MEMORY

“Red is done. Green is next.”

HeLM carries progress forward as text that guides the next action.

02 / THE METHOD

Remember in language.
Act through a robot policy.

HeLM separates deciding what comes next from executing the movement. The high-level vision-language model (HLP) manages memory; the low-level action policy (LLP) controls the robot.

  1. 01

    Notice an event

    Detect a meaningful change, such as a button press. If nothing happens, keep the memory.

    DETECT
  2. 02

    Update the memory

    Record the new progress and decide which action command should come next.

    UPDATE
  3. 03

    Execute the action

    The low-level policy turns the command and current observations into robot actions.

    ACT

Working memory

Go deeper: event-triggered updates +

Detect mode emits a task-relevant event or none. Update mode runs when an event is detected or the global instruction changes. Working memory tracks the current task; episodic context carries information across task boundaries.
