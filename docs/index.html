HeLM: Hierarchical Explicit Language Memory for Non-Markovian Manipulation

Gyeonghun KimDonghoon KimMinsoo ChoiSuyun Lee

Seoul National University

Code arXiv Video

Abstract

HeLM introduces explicit language memory for VLM-guided non-Markovian manipulation. A high-level vision-language model maintains working memory within an episode and episodic context across episodes. Memory is updated when a task-relevant event occurs, and action commands guide a low-level robot policy.

We evaluate HeLM on 10 real-world tasks with 56 variants, covering counting, ordered actions and object history, including five inter-episode tasks that require persistent context across instruction boundaries. HeLM improves intra-episode subtask success by 12.8 percentage points over the strongest baseline and achieves 78% subtask success on compositional generalization tasks. The paper reports up to 4.5× less memory and 2.5× faster inference than the keyframe baseline at long horizons.

02 / THE METHOD

HeLM framework

Hierarchical Explicit Language Memory

HeLM separates deciding what comes next from executing the movement. The high-level vision-language model (HLP) manages memory; the low-level action policy (LLP) controls the robot.

HIGH-LEVEL POLICY · VLM

HLP: detect events and maintain memory

Detect and Update are two modes of the same vision-language model.

    Visual Event Detection

  2. 02

    Memory Update

    When an event is detected or the instruction changes, update language memory and choose the next action command. Otherwise, retain both.

01Failure analysisResearch question: Which components account for the observed task failures?+

The main-text analysis identifies Detection and Low-Level Execution as the dominant HeLM failure categories; Termination failures were not observed. Table 7 provides the per-task breakdown.

02Memory and HLP fine-tuningResearch question: How do explicit language memory and HLP fine-tuning affect task success?+

All configurations use π₀.₅ as LLP. On T3–T8, HeLM achieves 45.8% task success, while both HLP ablations achieve 0%.

03Two-stage inferenceResearch question: Does separating event detection from memory updates improve subtask success?+

The one-stage variant jointly predicts events, memory and commands at each HLP call. HeLM separates event detection from event-triggered updates.

04Compositional generalizationResearch question: Can the HLP handle held-out task compositions without additional fine-tuning?+

Held-out variants combine learned subtasks without additional HLP fine-tuning. ★ indicates failure to terminate.

05Task-length robustness and memory scalingResearch question: How do task success and inference cost change as task history grows?+

A1 remains at 100% through seven subtasks; A2 ranges from 77% to 100%. At long horizons, the paper reports up to 4.5× less memory and 2.5× faster inference than Keyframe-HLP with the same Qwen2.5-VL-7B HLP backbone.
